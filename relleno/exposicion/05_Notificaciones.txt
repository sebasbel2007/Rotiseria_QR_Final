GUÍA DE EXPOSICIÓN: NOTIFICACIONES EN ROTISERÍA SYM
================================================================================

FECHA: 2026-09-03
VERSIÓN: v12.4

--------------------------------------------------------------------------------
1. ¿QUÉ SON LAS NOTIFICACIONES EN EL SISTEMA?
--------------------------------------------------------------------------------
Alertas automáticas en tiempo real que aparecen como globos nativos del navegador
sin recargar la página. Avisan a cocina/cajero/TV de eventos clave:
- Pedido nuevo → cocina
- Pedido listo → cliente / mozo
- Pago confirmado → caja
- Cambio de estado cocina

--------------------------------------------------------------------------------
2. ¿CÓMO SE IMPLEMENTAN EN WEB APP?
--------------------------------------------------------------------------------
DOS PIEZAS:

A. Notification API (navegador)
- Pide permiso: `Notification.requestPermission()`
- Crea notificación: `new Notification(título, { body, icon, tag })`
- Requiere HTTPS (ngrok en dev, dominio real en prod)

B. Firebase onSnapshot (tiempo real)
- Escucha cambios en Firestore
- Dispara notificación SOLO si el doc cambió a estado relevante

--------------------------------------------------------------------------------
3. IMPLEMENTACIÓN EN ROTISERÍA SYM (cocina.js / tv.js)
--------------------------------------------------------------------------------
```js
// 1. Pedir permiso al cargar (una vez)
Notification.requestPermission().then(perm => { /* guardamos perm */ });

// 2. Escucha pedidos activos (tiempo real)
db.collection('pedidos')
  .where('estado_cocina', 'in', ['Pendiente', 'En Preparación'])
  .onSnapshot(snapshot => {
    snapshot.docChanges().forEach(change => {
      if (change.type === 'added') {
        mostrarNotif(`🍽 Pedido nuevo - Mesa ${doc.mesa_id}`, doc.items);
      }
      if (change.type === 'modified' && change.doc.data().estado_cocina === 'Listo') {
        mostrarNotif(`✅ Listo - Mesa ${doc.mesa_id}`, doc.items);
      }
    });
  });

// 3. Función helper
function mostrarNotif(titulo, body) {
  if (Notification.permission === 'granted') {
    new Notification(titulo, { body, icon: '/icon-192.png', tag: 'pedido' });
  }
}
```

--------------------------------------------------------------------------------
5. PUNTOS CLAVE EXPO
--------------------------------------------------------------------------------
- No usamos Service Workers ni Push API (eso es para notificaciones con app cerrada)
- Solo funcionan con pestaña ABIERTA (Notification API + onSnapshot)
- Permiso se pide UNA vez; si niega → no hay notificaciones (fallback: sonido/visual en app)
- `tag: 'pedido'` evita duplicados si llegan varios eventos seguidos
- HTTPS obligatorio → en dev usamos ngrok (`https://*.ngrok-free.dev`)
